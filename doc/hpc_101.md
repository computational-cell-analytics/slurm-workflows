## Navigating the bash terminal
If you are new to the bash terminal, read this [introduction](https://cs.lmu.edu/~ray/notes/bash/).
The most basic commands are:
```bash
ls                                # list the files and directories
cd target_directory_name          # go to a directory
cd ..                             # go to the parent directory
cd ~                              # go to your home directory
cd -                              # go to the previous directory
pwd                               # show the path of the current directory
cp existing_file copied_file      # copy a file
mv old_file_name new_file_name    # rename or move a file
rm file                           # delete a file
exit                              # close the connection to the cluster
```

> [!CAUTION]
> `rm` deletes a file permanently. You cannot restore it.

## Quota

> [!NOTE]
> Each project has a [quota](https://docs.hpc.gwdg.de/how_to_use/storage_systems/quota/index.html) for storage space and for inodes.
> Each file and each directory uses one inode.

Check the usage of your user and your project:
```bash
show-usage
```

## Use screens

A `tmux` screen keeps a process running when the connection to the cluster ends. A screen also lets you run several processes at the same time.
```bash
tmux new -s 0    # create the screen 0
tmux a -t 0      # attach to the screen 0 again
```
In a screen, press `Ctrl+b` and then one more key:
* `d`: detach from the screen
* `w`: show the active windows
* `[`: start the view mode, e.g. to scroll. Stop it with `Ctrl+c`.

Type `exit` to close a screen.

> [!IMPORTANT]
> Use [Slurm jobs](https://docs.hpc.gwdg.de/how_to_use/slurm/index.html) for all work beyond simple actions, such as the copy or deletion of a small amount of data.
> For example, the MoBIE conversion, the transfer to the S3 bucket and the application of a neural network run as Slurm jobs.

## File permissions
Several users work in the same project. The permissions of a file or directory depend on its creator, see the [documentation](https://docs.hpc.gwdg.de/how_to_use/data_sharing/managing_permissions/index.html).

> [!IMPORTANT]
> Other project members can use your data only if the project group `HPC_<group_name>` owns it.
> E.g. the group of the HPC project `nhr_ni_test_28507` is `HPC_nhr_ni_test_28507`.

Give the project group the current directory and its content, with read and write access:
```bash
chgrp -Rh HPC_<group_name> .    # e.g. chgrp -Rh HPC_nhr_ni_test_28507 .
chmod -R g+rwX .
```

## Advanced scripts/functions

**List the files of the current directory that match a pattern**
```bash
find . -maxdepth 1 -name "pattern*with*wildcards"
```

**Rename several files in the current directory**
```bash
for f in *IMG*.jpg; do mv "$f" "${f/IMG/VACATION}"; done
```
The command renames `IMG_01.jpg`, `IMG_02.jpg` and `OLD_IMG_03.jpg` to `VACATION_01.jpg`, `VACATION_02.jpg` and `OLD_VACATION_03.jpg`.

**Check the storage space or the inodes of the directories that match a pattern**
```bash
du -d1 -B1 <pattern> | awk '$1 >= <size in bytes>' | numfmt --to=iec
# e.g. list the directories larger than 50 GB that match the cochlea format, e.g. M_AMD_000117_L
du -d1 -B1 *_*_*_* | awk '$1 >= 50*1024^3' | numfmt --to=iec
# e.g. list the directories with more than 10k inodes
du --inodes -d1 *_*_*_* | awk '$1 >= 10*1024' | numfmt --to=iec
```

**Check your jobs**
```bash
squeue --me
# show job names with up to 25 characters
squeue --me -o "%.18i %.9P %.25j %.8u %.2t %.10M %.6D %R"
```

### Working with your `.bashrc`

**Creating aliases**

An alias is a custom command. Define your aliases in `~/.bash_aliases`.
To load the file in each new terminal, add these lines to your `~/.bashrc`:
```bash
if [ -f ~/.bash_aliases ]; then
    . ~/.bash_aliases
fi
```
To load the file in the current terminal, run `source ~/.bash_aliases`.

Example content of `~/.bash_aliases`:
```bash
# give the project group the current directory and its content
alias editgroup='chgrp -Rh HPC_nhr_ni_test_28507 .'
# give the project group read and write access to the current directory and its content
alias editrights='chmod -R g+rwX .'
# set variables for frequent directories, e.g. for `cd $MOBIE_DIR`
export COCHLEA_DIR='/path/to/cochlea-lightsheet'
export MOBIE_DIR="$COCHLEA_DIR/mobie_project"
```
